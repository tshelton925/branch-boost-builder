# Blog briefs: shared standards (read before any brief)

**From:** Content strategist, 2026-11-15. **For:** blog writers, editors, the brand/SEO consistency team.
**Plan:** `05-content-keywords/content-plan.md` (decisions, ranking, calendar) and `05-content-keywords/blog-plan.csv`.
**Rules that override everything here:** `00-project/KNOWN-CORRECTIONS.md` (F1–F18, D1–D8), then `00-project/brand-voice-and-compliance-guide.md`, then this file.

Every brief in this folder is for a **new URL that has been checked against the 424-article library, the money pages and the tools.** Each one owns a narrow query set that no existing page owns. If you find yourself writing a section that another page owns (the brief names those pages under "Do not target"), write two sentences and link to that page instead.

## 1. Format and length

- **1,500 to 2,500 words.** Each brief gives a target range. The library median is 5,604 words; we are not adding to that pattern. Cut anything that does not answer a question in the outline.
- Model the format on the three concise Michigan glossary guides (`/learn/michigan-taxable-value/`, `/learn/michigan-transfer-tax/`, `/learn/michigan-land-contract/`): a short answer up top, question-led H2s, one Michigan table, a short FAQ, Sources.
- **Do not add the standard template tail** of "How Align …" + "The bottom line on …" + "Related resources" as H2s. Use one short "How Align can help" paragraph (not a heading) before the FAQ, then the FAQ, then Sources. Related links go inline, where the reader needs them.
- 8 to 12 H2s maximum. No H2 or H3 that is a number, price or label ("$10,000", "Key benefits").

## 3. CTA rules (F11, F11b, brand guide §5.2)

- **Booking buttons read "Talk with Samantha"** and open Calendly (`https://calendly.com/samanthashelton`, plus the CTA team's UTM pattern `?utm_source=alignlending&utm_medium=website&utm_campaign=learn&utm_content=module` or `end`). Pair with the reducer "No credit pull to talk."
- **Apply buttons read "Start my application"** and go to `/start/?goal=buy` (or `goal=refi` / `goal=equity`). Never pair an apply button with "No credit pull to talk." Until Align confirms where the credit pull happens, an apply button carries no friction reducer.
- **Plan and tool buttons** use the standard labels the brief names and open that page, never a calendar.
- Placement: one CTA module right after the first answer section (about 14% into the text, the CTA team's `al-module` position), one end block before the FAQ. No apply CTA next to any worked example (F12, Editorial Policy).
- No urgency words. No exclamation points.

## 4. Compliance cautions that apply to every post

- **No rates, APRs or payments that Align offers**, anywhere: body, tables, alt text, schema, meta (F13).
- **Reg Z trigger terms** (12 CFR 1026.24(d)): down payment amount or percentage, number of payments or repayment period, payment amount, finance charge. In Learn posts a program rule may be stated **as the agency's rule, with the agency named and linked** ("HUD sets FHA's minimum down payment at 3.5% of the price for borrowers with a credit score of 580 or higher"). Never as an Align offer, never in the same block as an apply CTA. Flag any table that shows these as `[COMPLIANCE REVIEW]`.
- **Worked examples** carry exactly: "Hypothetical example, not an offer. Actual rates, costs and payments vary." (F12) and state what any figure includes.
- **Michigan property tax wording** (F4, F16): "The year after a home sells, its taxable value resets to the state equalized value, half of the assessor's market value, not automatically half the price you paid." Statewide median homestead millage: **36.0 mills (2025 rates)**, Align's corrected Uncapping Study. Because taxable value resets to roughly half of market value, 36.0 mills works out to **about 1.8% of market value a year** after the reset. Never "1.5%" and never "your taxes will double".
- **PRE deadlines** are June 1 and November 1 (F5). **Conforming limit**: write "the 2026 limit of $832,750 (one unit)", and link `/loan-limits/` instead of restating it where you can (F6). **Conventional credit**: no fixed 620 floor; Fannie Mae's DU evaluates credit for case files created on or after November 16, 2025, and lenders may add overlays (F3).
- **MSHDA** (F1, F2, D3): First-Generation DPA is closed. Default Align wording: "Samantha explains the MSHDA programs and, if one fits, refers you to a participating lender."
- **Fair housing**: describe programs, homes, taxes and public records. Never describe who lives somewhere or call a place safe, desirable or family-friendly. Use person-first language for disability.
- **Banned words** (brand guide §6): best, top, leading, seamless, hassle-free, dream home, journey, unlock, low rates, guaranteed approval, pre-approved in minutes, act now, and the rest of that list.
- **Never invent** quotes, stories, statistics, closing times, lender counts or review counts.

## 5. Schema (JSON-LD, one graph per post)

Use the existing Learn pattern (Article with author Person and NMLS `PropertyValue`, FAQPage, SpeakableSpecification) and add BreadcrumbList and a `citation` list that matches the Sources section. FAQ text in the schema must match the visible FAQ **word for word**. HowTo only where a brief says so (Google no longer shows HowTo rich results, so it is for machine readability only, and only when the steps are a visible ordered list).

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "Article",
      "@id": "https://alignlending.com/learn/{slug}/#article",
      "headline": "{H1}",
      "description": "{meta description}",
      "datePublished": "{YYYY-MM-DD}",
      "dateModified": "{YYYY-MM-DD, must equal the visible Updated date}",
      "author": {
        "@type": "Person",
        "name": "Samantha Shelton",
        "jobTitle": "Broker Owner and Senior Loan Originator",
        "identifier": {"@type": "PropertyValue", "propertyID": "NMLS", "value": "1647301"},
        "url": "https://alignlending.com/samantha-shelton/"
      },
      "publisher": {"@id": "https://alignlending.com/#organization"},
      "mainEntityOfPage": "https://alignlending.com/learn/{slug}/",
      "citation": ["{each Sources URL}"],
      "speakable": {"@type": "SpeakableSpecification", "cssSelector": [".al-answer", ".al-takeaways"]}
    },
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        {"@type": "ListItem", "position": 1, "name": "Home", "item": "https://alignlending.com/"},
        {"@type": "ListItem", "position": 2, "name": "Learn", "item": "https://alignlending.com/learn/"},
        {"@type": "ListItem", "position": 3, "name": "{hub name}", "item": "https://alignlending.com/learn/{hub}/"},
        {"@type": "ListItem", "position": 4, "name": "{short title}", "item": "https://alignlending.com/learn/{slug}/"}
      ]
    },
    {
      "@type": "FAQPage",
      "mainEntity": [
        {"@type": "Question", "name": "{visible question}", "acceptedAnswer": {"@type": "Answer", "text": "{visible answer, word for word}"}}
      ]
    }
  ]
}
```

The Organization node (`#organization`) is defined site-wide by the refinance/home team's JSON-LD. Do not redefine it in the post. Never add `AggregateRating`, `Review`, `interestRate`, `annualPercentageRate` or `loanTerm`.

## 6. Images

- One hero or lead graphic per post, plus at most one inline diagram or table graphic. **Keep regulated figures out of images** (limits, fees, income caps change each year); put them in HTML tables that can be edited on release day.
- WebP, hero ≤ 150 KB, inline ≤ 80 KB, width and height set, the hero (LCP) not lazy-loaded, everything below the fold lazy-loaded.
- No photos or AI images of people presented as real clients, residents or staff. No people chosen or described to signal who lives somewhere. Alt text describes the content, never people's characteristics, never a rate.
- Open Graph image: 1200 × 630, same graphic, text-free or title-only. Coordinate file names with the images team (`07-images/`).

## 7. Internal links

- Anchors in each brief are exact. Use each anchor once. Place the money-page or tool link in the first 30% of the body.
- Links marked **(new, link once live)** point to another sprint post: add them when that post publishes, or the editor adds them in the next pass.
- Never link `/purchase/mortgage-readiness-review/`: the purchase team is 301-redirecting it to `/purchase/homebuyer-game-plan/#readiness`. Use the game plan URL.
- The "Inbound" list in each brief is work for the editor on publish day: add the named sentence and anchor to each existing article (first 30% of its body where possible), so the new post is never an orphan.

## 8. Pre-publish checklist (short form of brand guide §11)

- [ ] Title ≤ 60, meta 140–160, H1 as briefed, slug as briefed.
- [ ] Opening answer within 60 words; every question H2 opens with a 40–60 word answer.
- [ ] Word count inside the brief's range.
- [ ] No rate, APR or payment offer; trigger terms only as agency rules; examples labeled; no apply CTA beside an example.
- [ ] F7 government line where FHA/VA/USDA appear; MSHDA wording per F2.
- [ ] Every figure dated and sourced, or `[VERIFY]` left in place.
- [ ] Byline, updated date, entity statement, disclosure line, Sources with the editorial-policy link.
- [ ] Visible FAQ equals the FAQPage JSON-LD word for word.
- [ ] Outbound internal links placed; inbound links added to the listed articles.
- [ ] Draft saved in `06-blogs/drafts/{slug}.md` with "Subject to Align approval" and its source list (Regulation N recordkeeping).
- [ ] After publishing: submit the URL through Rank Math Instant Indexing (IndexNow, for Bing and Copilot) and request indexing in GSC.
